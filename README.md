### Featured Projects

**[AI Research Paper Assistant](https://github.com/mahek12345678/ai-research-paper-assistant)** · `Python` `FastAPI` `ChromaDB` `Groq` `PyMuPDF`
A full-stack Retrieval-Augmented Generation (RAG) system for real-time Q&A over research papers. Built a FastAPI backend integrating PDF ingestion, a vector database, and an LLM API into a single pipeline. Includes a custom document-processing pipeline (boilerplate deduplication, configurable-overlap chunking) to handle multi-column layouts and repeated headers/footers, with semantic retrieval via sentence embeddings feeding grounded, source-attributed answers. Deployed on Railway.
[Live Demo →](https://ai-research-paper-assistant-production.up.railway.app/)

**[Lendora AI](https://github.com/mahek12345678/Leondra-AI)** · `Python` `Scikit-learn` `Streamlit`
A loan underwriting dashboard powered by a Gradient Boosting pipeline across 16 engineered financial features (loan-income ratio, asset coverage, EMI proxy). Benchmarked against Logistic Regression, achieving **93.8% F1** and **0.98 ROC-AUC** on held-out data.
[Live Demo →](https://leondra-ai-chaqengyiqkmntktq7aeet.streamlit.app/)

**[Customer Churn Prediction](https://github.com/mahek12345678/customer-churn-prediction)** · `Python` `Scikit-learn` `Streamlit`
End-to-end churn model on the IBM Telco dataset — compared Logistic Regression, Decision Tree, and Random Forest (GridSearchCV-tuned), reaching **80.4% accuracy** and **61% F1**, with tenure, contract type, and monthly charges identified as top churn drivers via feature importance analysis.
[Live Demo →](https://customer-churn-prediction-cxuhxaagk3zqqntyszefl8.streamlit.app/)

**[Titanic Survival Prediction](https://github.com/mahek12345678/Titanic-Survival-Prediction)** · `Python` `Scikit-learn`
Classic classification pipeline covering data cleaning, exploratory analysis, and model comparison on the Titanic dataset.
